## I-003 | 2026-11-20 | 실행기 새 판의 무결성이 GitHub Releases + latest.yml sha512 에만 기댄다
- **상태**: 열림
- **심각도**: 보통
- **증상/내용**: 서명이 없어 electron-updater 가 게시자(`publisherName`)를 검사하지 못한다. 저장소 쓰기 권한이 털리면 새 판을 바꿔치기할 수 있다.
- **위치**: `src/updates.cjs` · `package.json` build.win
- **임시방편**: 올리기는 태그 job 에만 쓰기 권한(Actions) · latest.yml sha512 확인
- **해결 방향**: 인증서를 사면(I-001) 서명하고 `publisherName` 검사를 켠다

## I-002 | 2026-11-20 | (가) 웹에서 시작한 길에 challenge 가 없다 — 로그인 CSRF
- **상태**: 열림
- **심각도**: 보통
- **증상/내용**: 다른 사이트가 남의 접속 표로 `genius-online://pass#t=` 를 열면 실행기가 그 계정으로 접속될 수 있다.
- **위치**: 사이트 `/#/connect` (가) 길 · 이 저장소 `takeLink`
- **임시방편**: 표는 60초 · 한 번만 쓰이고, 실행기 ③ 계정 줄에 이름이 보인다
- **해결 방향**: 이미 접속 중일 때 다른 계정 표가 오면 사이트가 「다른 계정으로 바꿀까요?」를 묻는다(wavely-web 쪽 작은 일)

## I-001 | 2026-11-20 | 설치 파일에 코드 서명이 없다
- **상태**: 열림
- **심각도**: 보통
- **증상/내용**: 서명 없는 exe 라 처음 실행할 때 Windows SmartScreen 「Windows의 PC 보호」 경고가 뜬다(「추가 정보 → 실행」).
- **위치**: `package.json` build.win · Actions
- **임시방편**: 받기 화면(사이트 `/#/download`)에서 안내
- **해결 방향**: 코드 서명 인증서(OV/EV) 구입 뒤 Actions 비밀값으로 서명 — 소유자 결정 필요
